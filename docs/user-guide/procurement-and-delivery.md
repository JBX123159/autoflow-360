# 采购、仓库与交付操作指南

## 物料计划

销售订单提交后，打开订单并执行“计算物料缺口”。系统按每个物料显示订单需求、当前库存、已预留需求和净缺口；无缺口时不会生成采购需求。重复执行会更新或复用同一计划，不制造多份来源相同的物料需求。

## 询价与采购

1. 从已提交物料需求创建 RFQ，至少选择一个启用供应商。
2. 受邀供应商只能在门户看到自己的询价并提交自己的报价。
3. 采购核对币种、有效期、数量、仓库和交期，选择供应商报价生成采购订单。
4. 供应商更新 ETA 时必须填写原因；系统锁定采购单并记录修改前后日期、修改人和时间。已关闭/取消单据不能更新。

## 收货与库存

ERPNext 的采购收货和库存台账仍是事实来源。AutoFlow 只传播客户项目关联并在交付前读取实时 `Bin.actual_qty`。不要用手工字段代替收货过账，也不要通过修改项目摘要伪造库存。

## 客户交付

交付单每个项目物料必须来自已提交销售订单，项目必须一致，交付数量不得超过订单剩余数量。库存不足会在提交前被拦截。客户确认后生成唯一 `Customer Receipt`；可选证明文件必须由当前客户用户上传并设为私有。

## 异常处理

供应商延期、缺料、库存不足或交付偏差可形成确定性风险和业务异常。责任人填写根因、整改动作、负责人、截止日与私有证据；高风险异常由独立人员验证。不要直接编辑状态字段，所有转换都应使用页面按钮或受保护 API。
