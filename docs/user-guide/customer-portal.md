# 客户门户指南

客户门户账号通过 ERPNext Customer 的 `Portal User` 关系绑定。一个账号只能看到所属客户的项目、样品、已提交交付和签收记录；系统不会根据浏览器传入的客户名决定权限。

## 查看和反馈样品

1. 登录后打开“我的样品”。
2. 核对项目、轮次、规格、检验状态、承运商和运单号。
3. 只有已发出/等待反馈的样品可提交反馈。
4. 选择“客户认可”“重新打样”或“拒绝”，填写具体意见；附件必须先由当前账号上传。
5. 每一轮样品只接受一次最终反馈，提交后不能覆盖。需要重新打样时，由项目人员生成下一轮并保留前序记录。

## 确认交付

在“我的交付”查看已提交交付单及物料明细。货物核对无误后点击确认签收；需要上传签收证明时，应使用私有文件。系统再次校验交付客户与当前账号的 Customer 关系，重复确认会返回同一回执。

## 安全提示

不要共享账号，不在附件中上传身份证、银行卡或无关真实商业材料。若看见其他客户数据、无法识别的项目或非本人提交记录，应立即退出并通知管理员，不要继续下载或传播。
