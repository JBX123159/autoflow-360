# 供应商门户指南

供应商账号通过 ERPNext Supplier 的 `Portal User` 关系绑定。系统按“受邀 RFQ + 当前供应商”过滤询价、物料、会计科目选择和采购订单；浏览器修改请求中的供应商名称不会改变服务端身份。

## 提交报价

1. 登录后打开“询价”，只会看到当前供应商受邀且已提交的 RFQ。
2. 逐项填写单价、交期和必要说明，选择有效期。
3. 提交后系统核对当前账号对应供应商、RFQ 邀请关系、物料行和数量。
4. 同一 RFQ/供应商重复提交会复用未取消报价；需要变更时按采购流程处理，不创建来源不明的新单。

## 确认交期

打开“采购订单”，选择自己的已提交订单，填写新的预计到货日和变更原因。系统不允许修改其他供应商订单，也不允许修改关闭、完成或取消订单；每次变化会形成不可直接编辑的 ETA 历史。

## 数据边界

供应商不应看到客户项目完整资料、其他供应商报价、非受邀物料、其他公司的应收科目或内部风险/异常。发现越权迹象时停止操作并向管理员报告。演示环境仅含合成数据，不代表真实采购承诺。
