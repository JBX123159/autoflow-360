# 销售与项目人员操作指南

## 开始前

确认账号拥有 `AutoFlow Sales Operations` 或 `AutoFlow Project Manager`，并已配置负责公司或项目成员关系。进入“AutoFlow 工作台”后，只处理自己可见公司的项目；权限不足时联系管理员，不要使用共享管理员账号。

## 商机转项目

1. 在 Frappe CRM 打开已关联组织和联系人的商机。
2. 点击“转换为客户项目”，选择公司、产品族、目标定点日和客户交付日。
3. 服务端会校验目标定点日不得晚于客户交付日。同一商机重复点击会返回原项目，不生成重复记录。
4. 打开客户项目，检查来源商机、客户、公司、项目经理和里程碑。

## 样品与报价

创建样品后填写数量、规格、需求日和客户联系人。只有全部样品项检验通过才能发货；发货需要承运商和运单号。客户门户提交反馈后：

- 客户认可：可以继续报价。
- 重新打样：点击生成下一轮样品，系统保留上一轮来源。
- 拒绝：停止报价并记录下一步动作。

报价提交前系统检查客户认可样品和额度审批。超过规则金额时先发起审批；请求人不能审批自己的请求，且审批绑定当前报价快照。修改金额、币种、客户或公司后要重新审批。

## 订单与项目全景

已提交报价可转换为销售订单，重复转换会复用已有订单。项目页面“全景”展示样品、报价、销售订单、采购、交付、发票、付款、风险、异常与 AI 分析；打不开某条单据通常是权限边界生效，不应通过复制 URL 绕过。

## 结项

先打开结项状态，逐项处理交付、发票、付款、高风险和未关闭异常缺口。缺口清零后发起结项审批；源数据变化会使旧审批失效。正式关闭后，关键交付/财务证据禁止取消或回写。
