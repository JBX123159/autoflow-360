# 已知限制

## 产品与数据

- 项目只用合成数据验证，未上线真实企业、未产生真实营收、真实用户量或客户采用结果。
- 当前为汽车零部件 ToB 项目协同示例，没有覆盖完整制造执行、主生产计划、质量实验室或 EDI。
- 财务与库存能力来自 ERPNext；AutoFlow 增加关联和门槛，但不替代会计准则、税务配置或企业内控审计。
- CNY 是演示默认币种；未验证真实多币种汇率、税模板和跨境结算。

## 部署与可用性

- Oracle 免费层容量、区域库存和政策不受项目控制；免费不等于永久可用，也不等于零风险费用。
- Quick Tunnel 只适合临时面试展示，没有 SLA，不支持长期域名治理和完整访问策略。
- 单机 Compose 没有高可用、自动故障转移或跨区灾备；静态、完整集成和多架构镜像工作流已在公开仓库实跑，Oracle 脚本仍待真实云主机验收。
- 当前备份已通过 SHA-256 校验和一次性隔离站点恢复，但未自动加密、签名、异地上传或执行灾备切换演练。

## 安全

- 附件校验所有者和部分私有属性，但尚未统一限制业务 MIME、扩展名、魔数和单文件大小，也未接入恶意软件扫描。
- AI Base URL 只验证 HTTP(S) 和主机存在，尚未强制 HTTPS 域名白名单或阻止私网/环回地址；AI 默认关闭。
- 生产应用清单使用 ERPNext `version-16`、CRM `main` 和项目分支等可变引用；正式发布应记录实际提交并对镜像签名。
- GitHub Actions 使用官方 Action 主版本标签而不是完整提交 SHA；威胁模型已将其列为供应链残余风险。
- 仓库没有实现企业级 SSO、MFA、WAF、SIEM 和独立速率限制，部署时依赖 Frappe/反向代理/云平台并需额外配置。

## 性能与测试

- 性能是单机串行函数级测量，不是浏览器并发压测、耐久测试或 SLA。
- GitHub 托管环境每日风险扫描 P95 为 3904.756 ms；在项目量显著增大前仍需分批、索引和后台任务可观测性优化。
- 当前公开 `main` 的完整 Frappe 回归为 148/148、静态契约为 171/171、浏览器流程为 3/3；结果来自合成数据和单次 GitHub 托管环境，不代表生产负载。
- 当前 9 张业务截图已在本机真实站点采集并完成视觉验收；视频完整预览已获人工确认，最终 MP4 已完成本地渲染和视听验收。成片二进制不写入 Git 历史，已通过 `v1.0.0-rc2` GitHub Release 公开提供并完成匿名下载复核；当前仍没有长期公网业务 URL，不提供占位伪证据。

## AI

- AI 结果可能错误、遗漏或受提示注入影响，只能作为人工建议。
- AI 关闭时每周草稿任务返回 0，这是安全降级而非生成能力性能。
- 没有训练自有模型，也没有声称使用真实企业数据做训练或评测。
