# 3—5 分钟演示脚本

## 演示前 10 分钟

1. 启动本地站点，运行 `scripts/seed-demo.ps1`，确认返回 normal、supplier_delay、resample 三个项目。
2. 用无痕窗口检查演示账号；密码现场口述或单独发送，不写进仓库/视频。
3. 打开 AutoFlow 工作台，浏览器缩放 100%，关闭真实通知和其他标签页。
4. 若需要公网，运行 `scripts/start-tunnel.ps1`，只使用合成数据，演示后立即关闭。

## 0:00—0:40 项目定位

口述：“这是我基于 Frappe CRM 和 ERPNext 做的汽车零部件客户项目与供应链协同平台。上游负责标准 CRM、销售、采购、库存和财务，我新增的是从商机到项目、样品、审批、供应链、交付回款、风险整改和结项的可审计闭环。”

展示工作台的角色待办、项目列表和指标，说明数字来自合成数据。

## 0:40—1:40 正常交付

搜索 `DEMO-NORMAL-001`，进入项目全景。按时间线快速展示：客户认可样品、已审批报价、销售订单、物料/采购、交付签收、发票付款和已结项。重点说三件事：同源转换幂等；交付校验订单剩余量和实时库存；结项逐项核验交付、开票、付款与风险，不是手工改状态。

## 1:40—2:40 供应商延期

搜索 `DEMO-DELAY-001`。展示采购订单 ETA 偏离、确定性风险、业务异常、根因、整改动作、附件证据和独立验证。口述：“风险不是大模型猜出来的，它保存规则号、来源单据和快照；AI 只在外层做建议，失败也不会阻断业务。”

## 2:40—3:30 重新打样

搜索 `DEMO-RESAMPLE-001`。展示第一轮客户反馈“重新打样”、第二轮样品回链和新的客户认可。口述：“系统不覆盖旧反馈，轮次和来源保留；只有客户认可样品后报价才能提交。”

## 3:30—4:20 权限与工程证据

切到客户或供应商门户，展示只看到所属客户/受邀供应商的记录。回到 README/验收报告，展示 171/171 静态契约、148/148 完整集成回归、3/3 Playwright、全绿 GitHub Actions、`RESTORE_CHECK_PASSED` 及性能 JSON。镜像、公开地址和视频附件若尚未完成就如实标为待验收。

## 4:20—5:00 收尾

口述：“这个项目的价值不在于堆页面，而是把业务来源、权限、状态、幂等、审计、测试、部署和恢复放在一个证据链里。它未上线真实企业，所有数据都是合成数据；我可以继续讲权限矩阵、并发锁、结项门槛或 AI 安全边界。”

## 必须避免

- 不说“服务过某大厂”“真实上线”“提升多少营收”或任何未发生指标。
- 不展示 `.env`、管理员密码、数据库密码、AI key、真实个人信息或终端历史。
- 不在演示中临时修改生产数据、强制删除站点或打开不熟悉的外部链接。
