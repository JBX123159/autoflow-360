# 简历项目表述

## 70—100 字版本

基于 Frappe CRM 与 ERPNext 设计 AutoFlow 360 汽车客户项目及供应链协同平台，独立梳理商机、样品、报价审批、采购交付、回款结项闭环；实现九类角色数据隔离、风险整改、AI 来源审计、自动化测试及容器部署，全部以 CNY 合成数据验证。

## 项目经历完整版

**AutoFlow 360｜汽车零部件客户项目与供应链协同平台｜个人项目**

技术：Python 3.14、Frappe v16、ERPNext v16、Frappe CRM、MariaDB、Redis、Docker、Playwright、GitHub Actions

- 围绕汽车材料 BDM/客户项目协同场景，把 CRM 商机、样品反馈、报价审批、销售订单、物料缺口、供应商询价、库存交付、开票回款和结项串成可追溯业务主线；复用 ERPNext 标准单据，不重复造轮子。
- 设计七类内部角色、客户/供应商门户、项目成员和 Company User Permission 的行级权限；关键转换采用文件锁、数据库行锁、唯一来源与幂等检查，覆盖重复提交、越权和并发边界。
- 建立确定性风险/异常整改与可选 AI 建议层；AI 只读获权上下文、校验输出结构和来源，失败安全降级。完成 3 条端到端浏览器流程、可复现性能基线、CI、多架构镜像和备份恢复脚本。

## 面试真实性边界

该项目是个人求职作品，开发过程使用 Codex 等工具辅助检索、编码与测试，但需求取舍、业务建模、验收标准和最终交付由本人负责。项目未上线真实企业，未产生真实用户规模、营收或客户采用结果；所有账号、公司、金额、订单和性能规模均为合成数据。上游 Frappe CRM/ERPNext 提供标准能力，个人新增范围以 README 和贡献清单为准。
